# Long Toll Road — 长线产业投研系统

> 双系统架构：量化因子系统（V2）+ 主题驱动系统（V3）

---

## 总览

本项目服务于同一个投资理念——**在结构性增长行业中，找到有护城河的公司，以合理价格买入并长期持有。** 但在执行层面拆成了两个独立系统：

| | V2 · 量化因子系统 | V3 · 主题驱动系统 |
|---|---|---|
| **核心逻辑** | 用历史数据规律筛选好公司 | 用产业研究预判未来赛道 |
| **决策依据** | 财务报表 + 行业数据 + 回测引擎 | 产业政策 + 技术路线 + 竞争格局 |
| **持仓方式** | 15只 × 2年持有 | 5-10只 × 3-5年持有 |
| **预期收益** | 6-16% CAGR（可复现） | 15-30%+ CAGR（不连续） |
| **人力依赖** | 低（可自动化） | 高（需要研究员） |
| **当前状态** | ✅ 已完成 | 🔧 框架就绪，待持续投入 |

两套系统共享同一套数据基础设施（500家上市公司财务快照、价格数据、行业仪表盘），但在选股逻辑上完全独立。

---

## V2 · 量化因子系统

基于回测验证的定量选股系统。从500家上市公司中，通过赛道门+收费站门筛选出约318家可投公司，再用复合评分（赛道30% + 收费站40% + 估值20% + 质量10%）选前15名，等权建仓、持有两年。

→ **详细报告：[v2-quantitative/PROJECT-REPORT.html](./v2-quantitative/PROJECT-REPORT.html)**

### 核心回测结果（2016-2024，含交易成本）

| 变体 | CAGR | 最大回撤 | Sharpe | 相对基准 |
|------|------|---------|--------|---------|
| CSI800 基准 | +1.45% | -42.96% | 0.17 | — |
| V2 两年持有（保守） | +6.33% | -29.78% | 0.42 | +4.88pp |
| 两年持有（学术估算） | +16.01% | -13.0% | 0.86 | +14.56pp |
| 年度+停损+季证（最佳保守） | +6.68% | -10.84% | 0.95 | +5.22pp |

## V3 · 主题驱动系统

基于产业研究的定性选股系统。研究员通过分析产业政策、技术路线和竞争格局，提前识别结构性增长赛道（赛道），筛选有护城河的龙头公司（收费站），集中持有3-5年。

→ **详细介绍：[项目完整介绍.html](./项目完整介绍.html)**

### V3 目录结构

## 两套系统的关系

```
共享数据层（shared/）
├── 500家冻结人群定义
├── 43个季度财务快照
├── 486只股票日线价格
└── 396份年报PDF
        │
        ├──→ V2 量化因子系统
        │     自动运行，持续产生底仓
        │
        └──→ V3 主题驱动系统
              研究方向输出，交叉验证V2选股
```

在实际投资中，建议 **70%仓位跟随V2（底仓） + 30%仓位跟随V3（高弹性头寸）**。当V3的研究确认某个赛道正在爆发时，可在V2已有持仓的基础上加仓，实现量化筛选与定性确认的桥接。

## 快速开始

```bash
# V2 运行回测
cd v2-quantitative
python3 run_backtest_final.py

# V3 采集政策数据
cd v3-thematic
python3 research/fetch_policy_data.py
```

数据依赖：`shared/data/` 下的财务快照和价格数据需要从原始数据源恢复（已gitignore的约2GB文件不包含在仓库中）。
