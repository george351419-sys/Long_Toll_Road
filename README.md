# 长线产业投研系统

**完全抛弃 K 线、短线资金、舆论炒作**，以产业链信号交叉验证"必然需求"为唯一标尺。
每日自动扫描 24h 资讯/研报/财报/产业数据，输出标准化调研报告。

---

## 核心流程

```
每日扫描 ──→ 赛道评估 ──→ 收费站打分 ──→ 个股评估 ──→ 估值测算 ──→ 持仓风控
(daily)   (按需)     (按需)       (季度)     (季度)     (每日)
```

## 文件结构总览

| 目录/文件 | 用途 | 更新频率 |
|----------|------|---------|
| **每日扫描/** | | |
| `daily_scan.py` | 主入口脚本：生成搜索关键词 + 检查股价提醒 + 生成每日报告 | 每日运行 |
| `tracks.json` | 赛道配置与状态元数据（单一数据源） | 信号变化时 |
| `历史报告/` | 每日报告存档（YYYY-MM-DD-每日扫描.md） | 每日自动生成 |
| **系统/** | | |
| `1-赛道评估表.md` | 赛道筛选模板：四大准入 + 政策递进 + 确定性矩阵 | 评估新赛道时 |
| `2-收费站打分表.md` | 产业链拆解模板：六维 100 分 + 五维 10 分 | 赛道入选时 |
| `3-个股评估表.md` | 企业评估模板：四维 100 分 + 一票否决 | 季度财报后 |
| `4-估值测算表.md` | 估值定价模板：三段式贴现 + PE Bands + 买卖价 | 季度更新 |
| `score_calculator.py` | 计算引擎（交互/JSON 双模式） | 按需执行 |
| **价格跟踪/** | | |
| `price_checker.py` | 股价跟踪与提醒（支持交互/JSON/历史查询） | 每日检查 |
| `price_alerts.json` | 跟踪标的配置 + 目标价格 | 估值更新时 |
| **观察池/** | | |
| `pool_data.json` | 四级池结构化数据（环节/个股/持仓） | 数据变化时 |
| `README.md` | 池状态快览（从 tracks.json + pool_data 自动生成） | 运行 sync_pool.py |
| `sync_pool.py` | 数据同步脚本 | 数据更新后运行 |
| `kill_switch.py` | 赛道证伪级联清理脚本 | 触发证伪时 |
| **季度复盘/** | | |
| `quarterly_review.py` | 引导式季度复盘脚本（8 步流程） | 每季财报后 |
| `季度复盘模板.md` | 复盘报告模板（含上季对比） | 每季使用 |
| `weight_system.json` | 打分权重版本记录 | 权重调整时 |

## 每日运行流程

```bash
# 1. 进入每日扫描目录
cd 每日扫描

# 2. 完整检查：信号扫描 + 股价提醒 + 生成报告
python3 daily_scan.py

# 3. 更新股价
python3 ../价格跟踪/price_checker.py

# （可选）4. 同步观察池
python3 ../观察池/sync_pool.py

# （可选）5. 财报季后复盘
cd ../季度复盘 && python3 quarterly_review.py
```

## 赛道完整评估流程

```
发现新赛道信号
    │
    ▼
1-赛道评估表.md ──── 四大准入 + 政策递进 + 确定性矩阵
    │                         │ 通过
    ▼                         ▼
2-收费站打分表.md ─── 六维打分 + 五维确定性
    │                         │ 超级收费站(>=75)
    ▼                         ▼
3-个股评估表.md ──── 四维评估 + 一票否决
    │                         │ 长线龙头(>=70)
    ▼                         ▼
4-估值测算表.md ──── 三段式贴现 + 买卖价
    │
    ▼
更新 tracks.json + pool_data.json → 同步观察池
```

## 信号生命周期定位

| 阶段 | 特征 | 操作 |
|------|------|------|
| 预期差期 | 少数人知道 | 极小观察仓 |
| 共识形成期 | 产业圈共识 | 建观察仓 |
| 扩散期 | 大众关注 | 加仓期 |
| 泡沫期 | 人人讨论 | 减仓/退出 |

---

> ⚠️ 以上方法论由 AI 基于用户原创策略和圆桌专家讨论整理，仅供参考，不构成投资建议。

## 开发验证

项目回归测试仅依赖 Python 标准库：

```bash
python3 -m unittest discover -s tests -v
```

财务数据在线拉取功能额外依赖 `akshare`；其余打分、回测和本地报告功能不依赖第三方包。

为避免覆盖人工记录，每日扫描当天重复运行时默认保留已有报告和待办；
确需重新生成报告模板时使用 `python3 每日扫描/daily_scan.py --report-only --overwrite`。
