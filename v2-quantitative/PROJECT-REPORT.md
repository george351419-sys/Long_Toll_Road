# Long Toll Road — 完整体系V2 项目报告

> 生成日期：2026-07-25
> 版本：v2.0

---

## 一、项目概述

**核心问题**：能否在A股市场用系统化的方法，通过识别结构性增长赛道（Track）和具备护城河的公司（Toll），构建一个长期跑赢基准的策略？

**研究方法**：
- 冻结500家A股上市公司（含100家失败/退市样本）
- 采集2014-2024共43个季度财务数据
- 构建完整回测引擎，支持多维度消融分析
- 逐层验证：财务质量 → 赛道 → 收费站 → 估值 → 季度证伪 → 风控

---

## 二、策略框架

### 2.1 整体架构

```
500家冻结人群
  │
  ▼ 赛道门（行业健康度评分 ≥ 阈值）
~479家
  │
  ▼ 收费站门（公司护城河评分 ≥ 1.5）
~318家
  │
  ▼ 复合评分
  赛道(30%) + 收费站(40%) + 估值(20%) + 质量(10%)
  │
  ▼ 选前15名 → 等权建仓 → 持有两年
```

### 2.2 赛道评分（7个维度）

| 维度 | 权重 | 数据源 |
|------|------|--------|
| 毛利率水平 | 25% | 财务快照 |
| 营收增长稳定性 | 15% | 财务快照 |
| ROE水平 | 20% | 财务快照 |
| 毛利率趋势 | 10% | 财务快照 |
| 现金流质量 | 10% | 财务快照 |
| 专利密度 | 10% | 年报PDF提取 |
| 政策支持强度 | 10% | 五年规划/政策文件 |

覆盖129个行业，覆盖500家公司的季度数据。

### 2.3 收费站评分（3个因子）

```
收费站分 = 毛利率水平 × 毛利率稳定性 × ROE水平
         (最高35分)

分数 ≥ 1.5 通过收费站门
分数 ≥ 10  强护城河（可重仓）
```

通过率：约66%（479家 → 318家）

## 三、关键发现

### 3.1 持仓周期是最大瓶颈

```
买入首期15只股票后：

1年换仓: CAGR +12.74% ← 切得太短，卖飞大牛股
2年换仓: CAGR +16.01% ← 最优！赢家跑完大部分涨幅
3年换仓: CAGR +11.28% ← 太长，输家拖累
5年换仓: CAGR +9.03%  ← 同上
持有不动: CAGR +9.49%  ← 爆亏股拖9年
```

**核心洞察**：策略的瓶颈不是选股（复合评分已经能选出华测导航+850%和珀莱雅+686%），而是持仓周期。年化换仓把大牛股都卖飞了。

### 3.2 停损伤害长期收益

15%停损在第一年持有框架下有效（MDD从-28.5%降到-12.6%），但在两年持有框架下反而降低了CAGR（+6.33% → +5.98%）。原因是大牛股中间有-20%到-30%的跌幅很正常，停损会提前被洗出去。

### 3.3 赛道+收费站的有效性

在500家全样本中：
- 纯财务评分（V0）: CAGR +1.07%, MDD -50.47%
- 加赛道+收费站后: CAGR +3.16%, MDD -47.18%
- 加复合评分后: CAGR +3.51%, MDD -47.41%
- 加两年持有后: CAGR +6.33%, MDD -29.78%
- 加学术计算优化: CAGR +16.01%（无交易成本）

每层都增加了价值。赛道的价值在于排除最差的行业（房地产、林业、贸易等），收费站的价值在于排除没有护城河的公司，两年持有期的价值在于让赢家充分兑现。

## 四、回测结果总表

### 4.1 全样本消融分析（500家，含成本）

| 变体 | CAGR | 超额 | MDD | Sharpe | 说明 |
|------|------|------|-----|--------|------|
| CSI800基准 | +1.45% | — | -42.96% | 0.17 | — |
| V0（纯财务评分） | +1.07% | -0.38% | -50.47% | 0.16 | 原始基线 |
| V2（赛道+收费站） | +3.16% | +1.71% | -47.18% | 0.26 | 双门过滤 |
| +复合评分 | +3.51% | +2.06% | -47.41% | 0.27 | 更好的评分 |
| +15%停损 | +5.68% | +4.22% | -12.63% | 0.71 | 年度框架最优 |
| +季度证伪 | +6.68% | +5.22% | -10.84% | 0.95 | 最佳保守版本 |
| **V2两年持有** | **+6.33%** | **+4.88%** | **-29.78%** | **0.42** | **最终版本** |
| 两年持有（学术） | +16.01% | +14.56% | -13.0% | 0.86 | 无成本估算 |

### 4.2 最佳备选版本

```
一年持有+15%停损+季度证伪: CAGR +6.68%, MDD -10.84%, Sharpe 0.95
```

Sharpe 0.95是系统最高，MDD仅-10.84%。以Sharpe为评判标准是最优的。但绝对收益略低于两年持有策略的学术估算（+16.01%）。
