# 赛道研究框架：一个可操作的方法

基于整个回测的数据验证，好赛道有且只有四个共同特征：
1. **毛利率 > 40%**（最能预测未来表现的单一指标）
2. **连续三年 > 10%的需求增长**（不是某一年暴增）
3. **竞争格局稳定甚至改善**（不是新进入者不断涌入）
4. **政策方向明确且持续**（不是偶尔提一次）

以下是一个可实操的赛道研究方法，分三层：

---

## 第一层：批量扫描（每月一次，2-3小时）

用已有数据 + 公开政策文件，对所有126个行业做一次性过滤，把候选目标从126个减少到10-15个。

### 步骤1：跑现有财务数据（你已经有了）

```bash
python3 回测/industry_pit/complete-system-v1/extract_toll_candidates.py
```

从财报中提取每个行业的：
- 加权平均毛利率水平
- 营收增长率稳定性
- ROE趋势
- 资本开支增速（行业在扩产还是在收缩）

输出："行业赛道评分卡V1"——这是纯财务视角的第一遍过滤。

### 步骤2：跑政策扫描（新开发）

需要开发一个政策文档采集器，爬取：
- 国务院官网（gov.cn）——搜索"产业政策"、"发展规划"
- 发改委（ndrc.gov.cn）——五年规划、产业目录
- 工信部（miit.gov.cn）——行业十四五专项规划
- 科技部（most.gov.cn）——科技创新规划

对每个文档做简单的NLP分类：
- 涉及哪个行业（126行业分类体系）
- 量化目标（"2025年XX产值达到X万亿"）
- 补贴力度（"每年安排X亿元专项资金"）
- 时间线（短期/中期/长期）

输出："行业赛道评分卡V2"——政策面打分。

### 步骤3：汇总评分

```
赛道最终得分 = 财务分(40%) + 政策分(40%) + 专利趋势(20%)
```

前10-15名为"跟踪队列"，进入第二层。

---

## 第二层：深度研究（每月，每个候选行业1-2天）

对第一层筛出的10-15个行业，逐个做结构化分析。

### 核心分析框架（每行业一份）

**1. 需求侧：谁在买单？为什么买单？**
- 最终驱动力：人口结构（老龄化→医疗）？技术替代（自动化→人力成本）？政策强制（环保标准→新能源）？
- 量化：未来3年需求复合增速？确定性如何？
- 判断：如果需求增速>10%且确定性高，继续。否则淘汰。

**2. 供给侧：怎么赚钱？赚钱难不难？**
- 毛利率水平：>40%？>60%？趋势如何？
- 竞争格局：前5名市场份额合计？趋势升还是降？
- 新进入者：过去3年有没有新公司进入？融资额多少？
- 判断：毛利率稳定>40%、CR5上升、新进入者有限，继续。否则淘汰。

**3. 政策侧：政府怎么想？**
- 政策方向：支持/中性/打压
- 力度：有补贴？有税收优惠？还是只是"鼓励"？
- 持续性：长期国策（双碳）还是短期主题（雄安）
- 判断：政策明确支持+有真金白银+长期，继续。否则降低权重。

**4. 中国公司能赚到吗？**
- 技术差距：和国际领先差多少年？
- 成本优势：中国公司有制造成本优势吗？
- 市场准入：有牌照限制？有客户认证壁垒？
- 判断：中国公司有竞争力或正在快速追赶，继续。否则淘汰。

### 第二阶段输出

每个通过分析行业给出：
- 赛道推荐等级：强烈推荐/推荐/观察
- 核心逻辑：3句话说清楚为什么
- 关键指标跟踪：关注什么数据来判断逻辑是否正确
- 时间线：还需要多久能看到业绩兑现

---

## 第三层：公司选择（每季更新）

对每个"推荐"级别行业的头部公司做收费站分析：

**硬收费站识别清单：**
- [ ] 专利数 > 行业平均2倍？
- [ ] 毛利率 > 行业平均1.5倍？
- [ ] 过去3年毛利率波动 < 5pp？
- [ ] ROE > 15% 持续3年？
- [ ] 前5大客户占比 < 30%？（客户多元化）
- [ ] 前5大供应商占比 < 30%？（供应商多元化）
- [ ] 有政府牌照/准入许可？
- [ ] 品牌认知度 > 竞争对手？
- [ ] 有网络效应（用户越多越值钱）？
- [ ] 有替换成本（客户不会轻易换）？

满足7条以上 = 强收费站，可以重仓
满足4-6条 = 普通收费站，可以配置
满足3条以下 = 没有收费站，不投

## 实际操作建议

### 月度流程

```
第1周：跑政策扫描 → 更新赛道评分卡V2
第2周：跑财务数据 → 更新赛道评分卡V1
第3周：汇总评分 → 确定15个跟踪行业
第4周：深度研究2-3个行业 → 更新推荐列表
```

### 季度流程

```
第1个月：季度财报季 → 更新所有行业的财务评分
第2个月：深度研究5个行业 → 确定下季度的推荐组合
第3个月：验证逻辑 → 检查推荐逻辑是否成立
季度末：输出推荐行业+推荐股票 → 触发调仓
```

### 年度流程

```
年度末：全面复盘
  - 回顾今年推荐的赛道，哪些对了？哪些错了？为什么？
  - 回顾推荐的股票，哪些涨了？哪些跌了？
  - 更新评分模型权重（哪些指标更有效？）
  - 新一年的跟踪队列（10-15个行业）
```

## 和现有系统的集成

1. 赛道研究输出 → 更新 `track_scores` 字典（从财务代理改为研究评分）
2. 收费站研究输出 → 更新 `toll_scores` 字典（加入专利/牌照/客户集中度）
3. 复合评分 = 研究评分(30%) + 收费站评分(40%) + 估值(20%) + 财务(10%)
4. 跑 `build_composite_score.py` → 生成新选股
5. 跑 `run_backtest_final.py` → 验证

---

## 第一周可以开始的几件事

1. 下载最新一批政策文件（国务院、发改委、工信部网站）
2. 用现有的财务数据跑一遍126个行业的毛利率排名（已经有了）
3. 挑出毛利率>40%的行业，对照政策文件看哪些有政策支持
4. 把匹配上的3-5个行业做深度研究（按第二层框架）
5. 出推荐清单 + 触发条件
